# Bailey's Island — v6-based revision

Open `index.html` in a modern desktop browser. No installation or server is required.

## This revision

This project retains the original page structure, core stylesheet, home composition, scene flow, save system, and interaction architecture. Later visual and interaction refinements are collected in `game-polish.css` with targeted additions to the markup and script.

- Adds v9's complete Artwork & Game Guide images, cast-then-reel interaction, button sound, and two randomized transition treatments.
- Keeps v6's restrained Bailey's Island opening.
- Expands the v6 journey into four chapters and restores the first prototype's key interaction language and ferry ending.
- Removes star particles in favor of button glow/color feedback and adds subtle looping water, plant, character, and watering motion.
- Replaces Chapter I with the three-phase Beach Album flow: message/body mapping, five 2-second developing photographs with saved words, and a draggable soft-brush collage. Chapter I choices persist in `state.levels[0]` for later Who Am I use.

- Hand-drawn `bailey's island` opening animation, followed by a zoom-and-fade transition.
- Quiet homepage: large identity panel on the left, three sequentially unlocked level cards on the right.
- PPT-native visual system using the proposal's character, beach, phone, collage, ferry, fishing, and project images.
- Level 1 restores the phone-message reading scene before photography and emotion labeling.
- Level 2 keeps the flower-bench cue-reading interaction and uses a restrained short-consequence modal with replay.
- Level 3 keeps the sea ambience, reflective fishing interaction, direction choices, and ferry departure.
- Chinese/English toggle, pause, save-and-return, local autosave, per-level replay, and full journey reset.

Progress is saved in the browser's local storage. This conceptual prototype does not replace professional mental-health support.
