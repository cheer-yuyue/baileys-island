BAILEY'S ISLAND · 心的自留地
Playable Prototype v5（以 v3 为基底）

打开方式 / HOW TO OPEN
1. 解压整个文件夹。
2. 双击 index.html，用 Chrome、Safari、Edge 或 Firefox 打开。
3. 保持 assets 文件夹、styles.css、game.js 与 index.html 在同一目录结构中。

核心功能 / FEATURES
- 中文 / English 双语切换
- 三个关卡对应 Bailey 15–16、16–17、17–18 岁
- 四字关卡名：拾光辨心、花间回声、灯火归航
- 关卡依次解锁，进度自动保存在浏览器本机
- 游戏内随时暂停、返回主页；完成后可重新体验单关
- 首页可重置整段旅程，并保留语言与声音偏好
- 右上角“？”随时打开作品与游戏说明
- 原创舒缓环境音乐，可用右上角音乐键关闭
- 情绪颜色含文字标签：紧绷、低落、困惑、平静
- 插画式海滩收集、拍照、关系重演、钓鱼与灯笼互动
- 花田关卡先观察表情、距离与姿态，再开放对话回应

设计说明 / DESIGN NOTE
小岛不是永久躲避现实的地方，而是一处短暂停靠的“过渡空间”。
玩家通过观察、命名、重演和选择，把可带走的能力交还给 Bailey。

音乐说明 / MUSIC NOTE
此版本内置的是原创 Web Audio 舒缓环境音乐，不包含受版权保护的商业录音。
若之后提供拥有使用许可的《致远》音频文件，可再替换为指定曲目。

本作品为概念原型，不替代专业心理支持。
